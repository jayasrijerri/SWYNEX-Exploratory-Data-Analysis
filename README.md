# SWYNEX Exploratory Data Analysis

## Objective
Performed exploratory data analysis on a cleaned sales dataset using Microsoft Excel.

## Analysis Included
- Summary statistics
- Missing-value and duplicate check
- Category-wise sales analysis
- Region-wise sales analysis
- Sub-category analysis
- Monthly sales trend analysis
- Excel charts and insights

## Key Insights
- The dataset contains 9,800 records and 18 columns.
- No missing values or duplicate rows were found.
- Total sales are $2,261,536.78.
- Technology is the highest-sales category.
- West is the highest-sales region.
- Phones is the top-selling sub-category.
- A high-value sales outlier was identified.

## Tool Used
Microsoft Excel using PivotTables, PivotCharts and formulas.
